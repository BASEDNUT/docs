# 🌳 The Liquidity Tree

**Status: LIVE** — interactive map at [orchard.basednut.com/tree](https://orchard.basednut.com/tree).

A living liquidity map for NUT, SNUT, pNUT, nested tokens, and pools.

## What the Tree Shows

NUT anchors the structure. SNUT routes deflationary pressure. pNUT routes liquidity balance. Roots spread toward AMMs, pools, and LP depth.

| Element | Meaning |
|---|---|
| 🌰 Trunk / roots | NUT anchor — the root parent token anchoring the BASED NUT ecosystem |
| 🔥 Left branch | SNUT burn pressure — routes deflationary pressure through the ecosystem |
| 🌰 Right branch | pNUT liquidity balance — index/liquidity layer balancing deflationary forces |
| 🍃 Canopy | Nested token layers — bonding-curve child tokens |
| 🌱 Root nodes | LPs, AMMs, and depth — the liquidity root system |

The interactive map is an animated SVG: NUT trunk, SNUT burn branch, pNUT liquidity branch, nested token canopy, and LP root system. Click any node for its token profile.

## Why a Tree

The tree makes the ecosystem hierarchy visible at a glance: every token derives from NUT. NUT sits at the root, branching into SNUT (deflationary layer), pNUT (index basket), and Mint Club tokens (SALT, NUTINO). NFT collections (P-NUTS, ALMD, S-ALMD, PNUTRMY) appear as NUT-backed assets. The map is drawn from live on-chain state — pools, flows, curves, and arbitrage paths.
